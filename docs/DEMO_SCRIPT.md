# Recruiter demo flow

1. Open the deployed/local application.
2. Sign in.
3. Show the dashboard KPI cards.
4. Explain that the data is persisted in PostgreSQL.
5. Show the AI Coach and its explainable recommendations.
6. Show the next-week practice prediction and explain the scikit-learn model.
7. Open `/docs` and demonstrate the FastAPI OpenAPI contract.
8. Show MinIO and explain object-storage separation from relational metadata.
9. Create a practice session through the API.
10. Refresh the dashboard and show updated analytics.
11. Create a community post and show it in the feed.
12. Run `pytest` and show the passing test output.
13. Run the real-data importer and show captured Stack Overflow observations.
14. Show GitHub Actions CI and the repository structure.

Do not claim production scale, production uptime, or model accuracy beyond what you actually measure.
